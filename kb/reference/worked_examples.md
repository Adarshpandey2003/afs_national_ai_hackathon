# 2. Worked examples D01 and D02

Example answers prepared by the organizers, following the structure in section 3. Each is one defensible answer, not the only correct one, and contains no experimental results.

## D01  ·  Blend potency in a tablet press feed frame

Decision status  Provisional feasibility assessment.

Requirements stated  Powder blend with API and excipients; API concentration is the target; measurement in the feed frame is preferred; independent laboratory checks exist; the pilot should compare options before buying equipment.

Key unknowns  API and excipients, concentration range, acceptance limits, required response time, reference assay uncertainty, access and cleaning conditions.

### Clarification questions
1. Which API, excipients and concentration range are involved, and which changes must be distinguished?
2. Which assay, uncertainty and sampling time provide the reference concentrations?
3. Which formulation, particle and operating changes occur between runs?
4. What response time, acceptance limits, access and cleaning conditions apply?

### Recommendation

NIR (diffuse reflection).  The supplied pharmaceutical example supports NIR reflection for blend concentration in powders [S01 p.14–15]. A matrix-specific calibration must be built and tested [S01 p.10].

Raman.  The same application family supports Raman as a comparison candidate [S01 p.14–15]. Check fluorescence background and signal quality [S01 p.11].

NIR + Raman.  Consider only after each method has been assessed on its own. Whether the combination adds value for this formulation is a hypothesis to test [S01 p.14–15].

Measurement concept  A powder interface for each candidate in the feed frame, for example a diffuse reflection probe for NIR and a Raman probe [S01 Table 1 (p.6)]. A combined probe could sample the same spot, but probe type, installation and optical configuration need AFS confirmation.

Spectral range  NIR has a nominal method range of 780–2500 nm [S01 p.10]; specify only the usable range of the selected system. For Raman, state the excitation wavelength separately from the Raman shift. Do not pick an optimal band without sample spectra.

### Risks and uncertainty
- A change of API or excipients can invalidate a calibration.
- Physical variation of the powder (particle size, density, flow) changes the signal.
- A combination of methods does not guarantee a gain for every formulation.
- No accuracy, update rate or equipment compatibility has been confirmed.

### First feasibility experiment
1. Prepare representative blends across the client-agreed API range and the relevant physical variation.
2. Record spectra from each candidate together with independent API reference assays and timing information.
3. Build single-method models first, then a combined model; validate on held-out runs or batches.
4. Compare prediction error, bias and the ability to follow changes against the client’s requirements.

Decision basis  Agree numerical acceptance criteria with the client before the test. Choose the simplest configuration that meets them on independent material.

Sources  S01 p.6, 10, 11, 14–15.

## D02  ·  Fat and protein monitoring in opaque dairy product

Decision status  Provisional feasibility assessment.

Requirements stated  Opaque concentrated milk product in a flowing line; fat and protein are the targets; temperature and texture vary; laboratory checks remain available.

Key unknowns  Product types and composition ranges, required accuracy and delay, installation point, cleaning regime.

### Clarification questions
1. Which product types, composition ranges and reference assays are involved?
2. How do temperature, texture, homogenisation state and air bubbles vary?
3. Can an optical interface see a representative sample and be kept clean?
4. What accuracy, delay, installation and cleaning limits apply?

### Recommendation

NIR (diffuse reflection).  The supplied dairy example supports NIR reflection for opaque or concentrated products [S01 p.17]. Consider another geometry only if the measured optical behaviour justifies it [S01 p.18].

Measurement concept  Test a reflection interface on representative laboratory samples before specifying the process installation [S01 Table 1 (p.6)]. Confirm contact geometry, fouling control and cleaning with AFS and the client.

Spectral range  780–2500 nm is the general NIR range [S01 p.10], not a required full coverage. Check which bands the instrument and fiber actually cover, then inspect the sample spectra.

### Risks and uncertainty
- Temperature, texture and scattering changes can mimic composition changes [S01 p.17].
- Fat and protein each need their own independent reference results.
- A reflection spectrum is not yet a fat or protein calibration.
- Interface ratings, signal stability and achievable errors are unknown.

### First feasibility experiment
1. Collect representative samples with independent fat and protein results across production variation.
2. Compare suitable optical geometries, first under controlled and then under realistic conditions.
3. Separate the effect of physical changes (temperature, texture) from composition.
4. Validate on independent production runs against client-agreed error and maintenance requirements.

Decision basis  Composition error and bias on independent production runs, together with maintenance and response needs. The acceptance targets come from the client; none is invented here.

Sources  S01 p.6, 10, 17, 18.
