A fiber-based feed-frame measurement of API concentration is worth testing. The simplest primary candidate is NIR diffuse reflection; Raman and fused NIR+Raman are comparison candidates. MIR-ATR is not recommended first. The pilot should compare these methods against independent laboratory reference assays and client-agreed acceptance criteria.

### Raman spectroscopy (Raman fiber probe, 785 nm excitation): comparison [S01 p.15; S01 Table 1 (p.6); S01 p.11]

## Risks and uncertainty

- No source gives feed-frame accuracy, limit of detection, response time or calibration effort; 'high speeds' is qualitative only. *(inference)* [S01 p.15]

- NIR bands are broad and overlapping, so a matrix-specific chemometric model is required and may be invalidated by changes in API or excipients. *(sourced)* [S01 p.10]

- Diffuse reflection is sensitive to surface characteristics and scatter, and the probe samples only 0.5–1 mm, so the measured volume may not represent the entire blend. *(sourced)* [S01 p.17; S01 Table 1 (p.6)]

- Raman signal is several orders of magnitude weaker than IR absorption and may be superimposed by fluorescence. *(sourced)* [S01 p.11]

- Combining methods adds cost and complexity; a fusion gain is a hypothesis to test, not a guaranteed improvement. *(sourced)* [S01 p.9; S01 p.15]

## Feasibility plan

**Objective:** Compare NIR diffuse reflection, Raman, and NIR+Raman for feed-frame API concentration monitoring and choose the simplest method that meets client-agreed acceptance criteria.

**Samples**

- Representative powder blends spanning the client-agreed API concentration range and relevant physical variation such as particle size, density and flow.

- Held-out batches or production runs for independent validation.

- Process samples taken from the feed frame under normal and varying conditions.

**Reference measurements**

- Independent laboratory API assay, such as chromatographic or equivalent laboratory assay, with sampling and analysis time recorded.

- The current laboratory method if its sampling volume, uncertainty and comparability to the probe volume are characterized.

1. **Laboratory screening of candidate methods**: Record NIR diffuse reflection and Raman spectra on representative powder samples; confirm usable spectral range, required resolution, and whether the API signal is visible at the concentration level. [S01 p.10; S01 p.11; S01 Table 1 (p.6)]

2. **Build and validate chemometric models against reference assay**: Build single-method PLS calibration or classification models for API concentration using independent reference assay values and timing information; validate on held-out samples. [S01 p.12; S01 p.15]

3. **Feed-frame trial with timed reference samples**: Test the best single-method candidates in the real feed frame against timed reference samples; check robustness to powder flow, vibration, dust, and fouling. [S01 p.15; S01 p.17]

4. **Compare single methods, then optional fusion**: Compare single-method prediction error, bias, and ability to follow changes; test NIR+Raman fusion only if each method alone shows complementary value and the added complexity is justified. [S01 p.15]

5. **Outlook for simplified sensor**: If a model is successful, identify the key wavelengths and assess whether a dedicated LED/multisensor system could replace laboratory spectrometers; this is a later simplification step, not a pilot requirement. [S01 p.9]

**Comparison:** Compare NIR and Raman as single methods first; then compare the best single-method result with NIR+Raman fusion. Use client-defined criteria such as prediction error, bias, ability to follow concentration changes, robustness, cost, and ease of use.

**Go / no-go:** Agree numerical acceptance criteria with the client before testing; select the simplest configuration that meets them on independent material.
