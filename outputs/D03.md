## Recommendation

### NIR transflection probe (Near-infrared transflection/transmission measurement with a controlled path length of about 1–10 mm): primary

- NIR transmission/transflection is the preferred method for transparent or semi-transparent liquids such as skim milk, whey, or permeate; the optical path length is usually 1–10 mm. *(sourced)* [S01 p.18]

- A transflection probe can already be a combined solution working well for low-fat and high-fat containing milk products; the NIR spectrometer and light source remain the same for reflection and transmission techniques. *(sourced)* [S01 p.18]

- NIR is a common online analysis method using fiber optic probes, but broad overlapping absorption bands require chemometrics for quantitative protein analysis. *(sourced)* [S01 p.10]

Applies if: Applicable if protein produces a usable NIR signal and the selected path length works across the client's clear-to-turbid range.; Must be confirmed on representative whey samples before specifying the process installation.

### Dual NIR transmission and reflection (NIR transmission/transflection for clear conditions plus NIR diffuse reflection for turbid or scattering conditions): comparison

- Maintaining both NIR reflection and transmission provides flexibility across dairy physical states: transmission fails when milk becomes too thick or fat-rich, while reflection can work in highly scattering environments but can be less representative for clear liquids. *(sourced)* [S01 p.18]

- Inline NIR reflection is used for opaque or concentrated dairy and applies scatter correction, but it is sensitive to surface characteristics and fat globule size. *(sourced)* [S01 p.17]

Applies if: Test only if a single transflection probe is not robust enough across the observed turbidity range.

### MIR ATR probe (Mid-infrared attenuated total reflection probe with short optical path depth): comparison

- MIR ATR has high selectivity and a short path depth, making it a candidate when scattering or turbidity limits transmission measurements. *(sourced)* [S01 Table 1 (p.6)]

- The ATR principle uses an evanescent wave that penetrates only a few micrometers, enabling highly scattering fluids to be measured without dilution; this is stated for UV-ATR and is inferred to apply in principle to MIR ATR. *(inference)* [S01 p.16]

Applies if: Consider only if NIR transflection or dual NIR fails in the turbid state, because MIR ATR has high cost and contact/fouling limitations.

## Measurement concept

**Probe geometry**

- Primary concept: an NIR transflection probe with a defined sample layer and controlled path length, selected in the 1–10 mm range for transmission through the whey. *(sourced)* [S01 p.18; S01 Table 1 (p.6)]

- The same NIR spectrometer can be used with a reflection geometry if the transflection probe is not sufficient in highly turbid conditions; a transflection probe is itself described as a combined solution for low- and high-fat milk products. *(sourced)* [S01 p.18]

## Risks and uncertainty

- NIR protein bands overlap and selectivity is rated average, so a matrix-specific chemometric calibration is required rather than a simple single-wavelength reading. *(sourced)* [S01 Table 1 (p.6); S01 p.10]

- Path length is a trade-off: too wide loses signal to absorption, too narrow samples a negligible volume; turbidity can saturate a transmission/transflection setup. *(sourced)* [S01 p.18; S01 p.16]

- Reflection measurements are sensitive to surface characteristics and fat globule size, so physical changes in the stream can mimic protein concentration changes. *(sourced)* [S01 p.17]

- Scatter correction is not automatically beneficial: in one scattering research dataset, SNV correction seriously deteriorated discrimination, so turbidity corrections must be tested for protein prediction. *(sourced)* [S03 p.11]

- No AFS source provides a validated accuracy, precision or response-time figure for protein in whey, so the proposed concept is a test candidate rather than proven performance for this stream. *(inference)*

1. **Laboratory screening of candidate geometries**: Record NIR transflection/transmission and reflection spectra on representative whey samples across the clear-to-turbid range; note saturation and path-length effects. [S01 p.18; S01 Table 1 (p.6)]

2. **Build and independently validate a chemometric protein model**: Build a PLS or similar protein calibration against the agreed laboratory reference method; test scatter corrections only if they improve independent validation. [S01 p.10; S01 p.17; S03 p.7]

3. **In-line trial at the pre-concentration point**: Install the most promising probe concept at the actual process point and compare in-line spectra with timed reference samples under normal operation and turbid excursions. [S01 p.17; S02 p.3]

4. **Outlook: simplify to key wavelengths**: If the model works, identify the few informative NIR wavelengths for a simpler dedicated multi-wavelength or LED-based sensor. [S02 p.12; S02 p.18]

**Comparison:** Compare single transflection against dual NIR transmission/reflection and, if turbidity still limits NIR, MIR ATR; select the simplest configuration that meets client-agreed error and stability.
