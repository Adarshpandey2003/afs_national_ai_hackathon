**Objective:** Determine whether the existing feed-frame NIR measurement can be re-qualified for the new API/excipient blend and whether adding Raman as a new fused model is justified.

**Samples**

- Representative new-blend samples spanning the client-agreed API concentration range, including pure API and the new excipients where available.

- Historical spectra or model outputs from the existing NIR pilot for the old formulation, if available.

- Material varying in the physical factors expected at the feed frame (particle size, density, flow), agreed with the client.

**Reference measurements**

- Independent API concentration reference assay for calibration/validation samples, e.g. chromatography or mass spectrometry.

- Timed reference samples taken at the feed frame during any in-line trial.

1. **Scope the existing NIR calibration and setup**: Confirm spectral range, model type, validation history, and whether the old probe/fiber link can be reused. Treat the old calibration as formulation-specific until proven otherwise. [S01 p.10]

2. **Screen the new blend in the laboratory**: Record NIR diffuse-reflection spectra on representative new-blend samples and pure components to identify usable bands, overlap, and physical baseline effects before choosing a model approach. [S01 p.10; S01 p.14]

3. **Test the old calibration on the new blend**: Apply the existing model to new-blend spectra and compare with reference API results; expect bias/slope failure. Any apparent success is only a hypothesis for formal validation. [S01 p.10]

4. **Add Raman only if single-method NIR is insufficient**: Check Raman fluorescence early; record 785 nm spectra on the same samples. Build and validate new single-method NIR, Raman, and fused NIR+Raman models against independent reference data. [S01 p.11; S01 p.15]

5. **Run an in-line feed-frame trial and plan simplification**: Test the selected configuration at the real feed frame against timed reference samples and assess robustness. If the model works, reduce to key wavelengths for a dedicated multi-wavelength sensor. [S01 p.14; S01 p.15; S01 p.9; S05 p.1]

**Comparison:** Compare the old model vs reference API on the new blend; compare new NIR, Raman, and fused NIR+Raman models on held-out validation data; choose the simplest configuration meeting requirements.

**Go / no-go:** Go if the selected method meets client-agreed numerical acceptance criteria (prediction error, bias, response time) on independent feed-frame samples. No-go if the old model shows unacceptable bias and no new single or fused model meets the requirements.
