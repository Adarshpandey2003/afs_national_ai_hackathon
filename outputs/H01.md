We are introducing a different API and excipient blend and would like to reuse the calibration. A colleague suggests adding Raman so that the old calibration will remain valid. ## Feasibility plan

**Objective:** Determine whether NIR alone, or NIR+Raman fusion, can quantify API concentration in the new blend, and explicitly reject the idea of reusing the old calibration unchanged.

**Samples**

- Representative new API/excipient blend samples across the client-agreed API concentration range.

- A few old-formulation samples only for spectral contrast, not for transferring the old model.

**Reference measurements**

- Independent API concentration reference assay, such as HPLC or another named pharmacopoeial method, with documented sampling time and uncertainty.

1. **Laboratory screening of new blend**: Record NIR and Raman spectra on representative new-blend samples with standard laboratory spectrometers; check API-specific bands, excipient interferences, Raman fluorescence, and usable spectral windows. [S01 p.9; S05 p.1]

2. **Build single-method chemometric models**: Build an NIR calibration first against the independent reference API assay, then a Raman calibration if needed; validate on held-out samples before considering fusion. [S01 p.10; S01 p.12]

3. **Compare with fused NIR+Raman model**: Only if single-method models are insufficient, record synchronized NIR and Raman spectra from the same small area and build a fused PLS model; compare with the best single method. [S01 p.15; S01 p.8]

4. **Feed-frame trial**: Test the chosen candidate at the actual feed frame against timed reference samples; check robustness to powder flow, fouling, vibration, and drift. [S01 p.15]

5. **Outlook for simplified sensor**: If the model works, use the identified key wavelengths to evaluate a simpler dedicated multi-wavelength sensor; this is a later development step. [S01 p.9; S03 p.14; S05 p.1]

**Comparison:** Compare prediction error, bias, and robustness on independent samples for: NIR-only, Raman-only (if viable), and fused NIR+Raman. Choose the simplest configuration that meets agreed acceptance criteria.

**Go / no-go:** Agree numerical acceptance criteria with the client before the test (e.g., maximum prediction error and bias relative to the reference method). Go/no-go is based on independent validation samples, not on training data or the old calibration.
