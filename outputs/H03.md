## Recommendation

### NIR spectroscopy (Transmission/transflection probe for clear liquids; diffuse reflection if scattering media): primary

- NIR is the most common online analysis method using fiber optic probes and is effective for tracking major components like glucose or glycerol in the millimolar range. *(sourced)* [S01 p.10; S01 p.16]

- Glucose concentration is a major component in fermentation broth and should be tested first by NIR because it is simpler and lower-cost than Raman, while still requiring a matrix-specific calibration. *(inference)* [S01 Table 1 (p.6)]

### UV/Vis spectroscopy (Transmission/transflection probe for low-OD media; UV-ATR probe for high-OD/turbid media): primary

- UV/Vis spectroscopy can be deployed as a low-cost, robust tool for real-time biomass monitoring, as cell suspension turbidity correlates well with cell density. *(sourced)* [S01 p.16]

- Optical density is not a viable cell count, so this method provides a biomass proxy that must be calibrated against the client's independent viable-biomass reference. *(sourced)* [S01 p.16]

Applies if: Client defines viable biomass reference (e.g., viable cell count, CFU, ATP) and accepts a turbidity-based proxy calibrated against it.; Select UV-ATR if the broth becomes highly turbid or opaque at later fermentation stages.

### Raman spectroscopy (Raman probe (2–5 mm path)): comparison

- Raman provides a molecular fingerprint for direct detection of specific metabolites like glucose, acetate, or lactate and is well-suited for aqueous environments. *(sourced)* [S01 p.16]

- Raman has higher selectivity than NIR but weaker signal and fluorescence background, so it is a comparison candidate if NIR lacks selectivity for this broth. *(sourced)* [S01 Table 1 (p.6)]

## Measurement concept

**Probe geometry**

- For glucose by NIR, use a transmission or transflection probe for liquids and colloids (1–10 mm optical path); if the broth is strongly scattering, evaluate a diffuse reflection probe. *(sourced)* [S01 Table 1 (p.6)]

- For biomass by UV/Vis, use a transmission or transflection probe for low-optical-density media and a UV-ATR probe for high-OD/turbid media. *(sourced)* [S01 p.16; S01 Table 1 (p.6)]

## Feasibility plan

**Objective:** Determine whether one fiber-optic method (or a combination) can quantify glucose concentration and viable biomass in the customer's fermentation with agreement against client reference methods, and under what conditions an in-line sensor is justified.

**Samples**

- Representative fermentation broth samples covering the expected glucose and biomass ranges across several stages.

- Process samples taken at multiple fermentation times under physical variation (agitation, aeration, temperature).

- High-OD/turbid samples near the end of fermentation for probe geometry selection.

**Reference measurements**

- Independent glucose assay (e.g., enzymatic assay, HPLC) on aliquots taken at each spectral sampling time.

- Independent viable biomass reference defined by the client (e.g., viable cell count, CFU, ATP bioluminescence).

- Timed log linking spectra to reference samples for calibration and validation.

1. **Lab screening of candidate methods on representative broth**: Record UV/Vis, NIR, Raman and fluorescence spectra on the same samples using a multi-method fiber system; identify usable spectral ranges and signal quality. Do not assume the existing fluorescence spectrometer is sufficient. [S02 p.20; S02 p.3]

2. **Build chemometric models against independent reference data**: For glucose, test NIR and Raman calibrations; for biomass, test UV/Vis turbidity calibration against the client-defined viable biomass reference. Treat any fluorescence contribution as a combination channel only if a fluorescent target is identified. [S02 p.20; S01 p.10]

3. **Evaluate fluorescence contribution and data fusion**: If native fluorophores such as NADH, tryptophan or riboflavin are present, test whether adding fluorescence improves biomass or metabolic-state prediction; compare against the best single-method model before deciding on combination. [S01 p.16; S01 p.7]

4. **In-line/at-line trial at the real measurement point**: Install candidate probe(s) at an agreed bioreactor location and compare real-time predictions with timed reference samples; check robustness to agitation, aeration, temperature, fouling and high optical density. [S02 p.18]

5. **Outlook: simplify to key wavelengths if model works**: If a validated model is established, identify key spectral features and assess whether a dedicated multi-wavelength sensor can replace full spectra. The sources show this simplification concept in other applications, so feasibility must be confirmed for this broth. [S03 p.1; S04 p.4]

**Comparison:** Compare single-method predictions (NIR or Raman for glucose; UV/Vis for biomass) with the existing fluorescence spectrometer and with data fusion. Assess prediction error, bias, robustness to physical variation, and maintenance/fouling requirements.

**Go / no-go:** Agree numerical acceptance criteria with the client before the trial. Proceed to in-line trial only if a candidate model meets the agreed accuracy and response requirements on independent samples; if no single method suffices, test data fusion and a simplified sensor only after a validated model.
