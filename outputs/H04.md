## Feasibility plan

**Objective:** Determine by lab screening whether MIR ATR with a new MIR-compatible fiber or NIR with the existing silica cable can reliably quantify water in the customer's petroleum stream, before any in-line build or approval.

**Samples**

- Representative petroleum samples with client-defined water levels spanning dissolved, free or emulsified forms.

- Samples covering expected temperature, composition and physical variation of the production stream.

- Timed samples from the line if available, for later comparison with in-line measurements.

**Reference measurements**

- Independent water content results from a client-agreed reference method such as Karl Fischer titration.

- Reference method uncertainty and sampling time documented alongside each spectral measurement.

1. **Multi-method lab screening**: Compare MIR ATR with a laboratory MIR fiber/probe and NIR with the existing or standard silica spectrometer on the same representative petroleum samples with known water levels. Identify usable spectral range, sensitivity and hydrocarbon matrix background. [S02 p.3; S05 p.1]

2. **Reference-based calibration models**: Build single-method calibration models against the client-agreed reference water method. Use chemometrics for overlapping NIR bands and for small water features on the hydrocarbon background. [S01 p.10; S05 p.1]

3. **Compare single-method performance**: Compare MIR ATR with a new IR fiber against NIR with the existing silica cable on model error, bias, selectivity and installation complexity. Consider a combined method only if neither single method is sufficient. [S01 Table 1 (p.6); S02 p.13]

4. **In-line trial at measurement point**: Install the selected probe at the real petroleum line location with timed reference samples. Check robustness to temperature, flow, fouling and fiber-link variation. [S01 p.10; S02 p.13]

5. **Simplification outlook**: If a model meets client criteria, identify the few key wavelengths or spectral features that a simpler dedicated multi-wavelength sensor could use. If no method or link can be validated, stop. [S01 p.9; S05 p.1]

**Comparison:** Compare MIR ATR with a new MIR fiber against NIR using the existing silica cable on the same samples and independent water reference results. Evaluate model error, bias, selectivity versus the hydrocarbon matrix, cost and installation complexity.

**Go / no-go:** Agree acceptance criteria with the client before testing. Go if the selected method and fiber link meet those criteria on independent samples and in the in-line trial; no-go if no method or link can be validated with the supplied evidence.
